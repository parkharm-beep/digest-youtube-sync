개인정보처리방침 / Privacy Policy

시행일 / Effective: 2026-10-19

수집 항목 / Data accessed

YouTube Data API 읽기 전용 권한으로 소유자 본인 계정의 구독 채널 ID와 채널 이름만 읽습니다. 영상 시청 기록, 댓글, 이메일, 연락처 등 다른 정보는 읽지 않습니다.

Using the read-only YouTube scope, the app reads only the channel IDs and channel names of the owner's own subscriptions. It does not access watch history, comments, email or contacts.

이용 목적 / Use

소유자 본인이 받는 Slack 영상 요약의 수집 대상 채널 목록을 갱신하는 데에만 씁니다.

The data is used only to update the channel list of the owner's own Slack video digest.

보관과 제공 / Storage and sharing

채널 ID와 이름은 소유자가 관리하는 서버의 설정 파일에만 저장합니다. 제3자에게 판매하거나 제공하지 않으며, 광고에 쓰지 않습니다.

Channel IDs and names are stored only in a configuration file on a server controlled by the owner. They are never sold, shared with third parties or used for advertising.

권한 철회 / Revoking access

Google 계정의 서드 파티 연결 화면에서 언제든 이 앱의 접근 권한을 철회할 수 있습니다.

Access can be revoked at any time from the Google Account third-party connections page.

Google API Services에서 받은 정보의 사용은 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.
